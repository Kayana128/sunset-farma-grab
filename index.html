Belum ada file.
Alur yang dilakukan aplikasi:
1. Membaca kolom Barang dan Stok dari laporan stok mentah.
2. Mengisi data tersebut ke proses STOK OUTLET → RUMUS STOCK sesuai template Anda.
3. Melakukan pencocokan nama barang seperti VLOOKUP. Jika tidak ditemukan / N/A, stok dianggap 0.
4. Mengambil CODE + STOCK UPLOAD seperti sheet STOCK JADI.
5. Mengisi Current Stock pada sheet GRAB berdasarkan ID barang.
6. Jika Current Stock = 0, hanya Max Stock yang dikosongkan. Kolom lain GRAB tidak diubah.
7. Menghasilkan file GRAB Excel atau CSV yang siap digunakan untuk upload.
